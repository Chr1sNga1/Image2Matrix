# Image2Matrix
Make your image files on a color filter like the movie 'Matrix'.

让你的图片文件加上类似电影《黑客帝国》的颜色滤镜效果。

## Usage / 使用方法

Drag and drop an image file onto `run.bat` to apply the Matrix-style color filter.

将图片文件拖拽到 `run.bat` 上即可应用 Matrix 风格的滤镜效果。

### Supported Formats / 支持的格式

PNG, JPEG, JPG, BMP, GIF, TIFF, WEBP, ICO, PPM, PGM, PBM

## Requirements / 环境要求

- Python 3
- Pillow (`pip install Pillow`)

## Output / 输出

The processed image will be saved as `Matrix_<original_filename>` in the project directory.

处理后的图片将以 `Matrix_<原文件名>` 保存在项目目录下。
